# Identity and directory security

Identity security analysis for Active Directory and Windows authentication, including LDAP, Kerberos, NTLM, SMB, DNS, GPO, ACLs, delegation, trusts, SPNs, service accounts, certificates/AD CS, BloodHound relationships, local-admin edges, privileged groups, and domain authentication. Express paths as identity-permission-system-trust relationships, verify effective rights and prerequisites, and distinguish configuration exposure from exploitability. Use `active-directory-security`.
