# Application security

Application and product security analysis for architecture, trust boundaries, source code, dependencies, supply chain, authentication/authorization, secrets, cryptography, web/API behavior, and remediation. Trace reachable execution and data paths; verify source, sink, guards, prerequisites, and impact. Treat CVE/version matches and scanner output as leads until reachability is established. Use `application-security`, `web-security-assessment`, and `vulnerability-research` as applicable.
