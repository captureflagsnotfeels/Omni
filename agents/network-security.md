# Network security

Analyze PCAP, DNS, HTTP, TLS metadata, SMB, Kerberos, LDAP, RDP, SSH, DHCP, ARP, ICMP, firewall/proxy, Zeek, Suricata, and NetFlow. Build conversation and chronological views. Explicitly separate resolution, connection attempt, completed TCP handshake, TLS establishment, and application exchange. Use `network-forensics`.
