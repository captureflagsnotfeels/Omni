# Validate security controls

Automatically run a multi-agent workflow without requiring the operator to name agents: `offensive_security` explains the verified technique and prerequisites; `security_operations` locates supporting telemetry; `detection_engineering` builds behavioral detection; `control_validation` maps ATT&CK and visibility gaps; `security_assurance` independently challenges evidence, mapping, and detection quality. Parallelize independent read-only work and wait for all results.

Produce a final evidence-backed attack-chain summary. Include only supported stages among Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, Command and Control, Exfiltration, and Impact. For each supported stage provide evidence, ATT&CK mapping, telemetry, detection, gaps, mitigation, false positives/tuning, and validation. Omit unsupported stages.
