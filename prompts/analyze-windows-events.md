# Analyze Windows event logs

Use `digital_forensics`, `security_operations`, and `windows-forensics` automatically. Inventory available channels/providers and their coverage, then prioritize events relevant to the question rather than dumping Event IDs.

Correlate process creation, logons, account/group changes, PowerShell, WMI, services, scheduled tasks, Defender, DNS, firewall, and remote access. Interpret provider-specific fields, record IDs, host timezone, and success/failure status. Return Summary, exact supporting records, normalized Timeline retaining raw timestamps, Assessment, relevant gaps, and next targeted artifact/query.
