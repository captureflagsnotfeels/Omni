# Assess or investigate a cloud environment

Automatically use `cloud_security` and `cloud-security`. Establish provider, account/project/subscription, region, current identity, authorization, scope, and available logs. Analyze effective IAM, federation, resource policies, public exposure, networking, storage, compute/serverless, container/Kubernetes configuration, CI/CD identities, secrets, and infrastructure as code.

For offensive work, express each path as identity -> permission -> resource -> resulting privilege and verify prerequisites. For defensive work, correlate control-plane, identity, network, workload, storage, and configuration history; distinguish API attempts from successful actions. Return evidence, paths or timeline, risk/assessment, detection and remediation, gaps, and uncertainty.
