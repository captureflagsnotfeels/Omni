# Review an application or product

Automatically use `application_security` and `application-security`. Establish architecture, identities, data sensitivity, trust boundaries, entry points, and deployment context. Trace source, sink, validation, authorization, and reachable execution paths. Review dependencies and delivery-chain controls. Use `web-security-assessment` only for authorized live validation and `vulnerability-research` for deeper reproduction.

Return prioritized findings with affected component/path, evidence, prerequisites, boundary crossed, exploitability, impact, remediation, regression tests, and uncertainty. Do not report scanner or version matches as verified vulnerabilities without reachability and environmental evidence.
