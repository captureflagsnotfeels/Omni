# Analyze a network capture

Use `network_security` and `network-forensics` automatically. Hash and inventory the capture, then identify endpoints, DNS, conversations, protocols, suspicious traffic, authentication, possible command-and-control indicators, and transferred files when observable. Build a chronological network timeline.

Separate DNS resolution, connection attempt, completed TCP connection, TLS establishment, and application communication. State capture gaps and encryption limits. Return Summary, Evidence, Conversations/Timeline, Assessment, extracted-object hashes where applicable, and Remaining uncertainty.
