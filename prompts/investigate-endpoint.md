# Investigate an endpoint

Investigate the supplied host evidence for compromise in INVESTIGATION MODE. Automatically route independent work: `digital_forensics` reconstructs host activity/timeline; `network_security` analyzes DNS/connections; `malware_analysis` handles suspicious files/scripts; `security_operations` synthesizes the intrusion chain; `threat_intelligence` enriches only indicators that need external context. Use `security_assurance` to challenge material conclusions.

Identify evidence of execution, persistence, privilege escalation, credential access, discovery, lateral movement, network activity, and account changes. Include only stages supported by evidence. Preserve exact artifacts and timezones. Return Summary, Evidence, Timeline, Assessment/scope, ATT&CK mapping when justified, containment/detection/remediation, and Remaining uncertainty.
