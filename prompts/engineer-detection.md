# Engineer a detection

Give observed behavior and available telemetry in ordinary language. Automatically use `detection_engineering` and relevant SPL, KQL, Sigma, YARA, or network-forensics skills. Produce the formats supported by the actual data source—Splunk SPL, Microsoft KQL, and Sigma where applicable; add YARA, Suricata, PowerShell, or EDR logic only when suitable.

For each detection include security behavior, data source, required fields, query/rule, ATT&CK mapping, likely false positives, tuning, telemetry gaps, and validation procedure. Prefer behavioral logic; use static IOCs as supporting indicators. Do not claim coverage for fields or telemetry not present.
